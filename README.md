# Cms-shop — متجر Nasser Shop 🛍️

سكريبت متجر إلكتروني جزائري كامل (متجر واحد) يُثبَّت على أي استضافة cPanel مع MySQL.

## المزايا
- 🛒 شراء **كضيف** أو بحساب اختياري (هاتف + كلمة سر)
- 💵 **الدفع عند الاستلام** مع **69 ولاية** وسعر توصيل قابل للتعديل لكل ولاية
- 🌍 **ثلاث لغات**: العربية (RTL) / الفرنسية / الإنجليزية
- 🧑‍💼 **لوحة تحكم** كاملة: منتجات، فئات، طلبات، فواتير طباعة، عملاء، ولايات، صفحات، إعدادات
- 👥 **صلاحيات الموظفين**: owner / orders / products
- 🧾 **فاتورة قابلة للطباعة (PDF)** لكل طلب بهوية المتجر
- 🔍 بحث + فلاتر (فئة، سعر)، تقارير مبيعات، سجل تغييرات
- 🎨 تخصيص الاسم والشعار والألوان من لوحة التحكم

## التثبيت على cPanel (خطوات)
1. ارفع محتويات المجلد إلى `public_html` (أو مجلد فرعي).
2. أنشئ قاعدة بيانات MySQL من cPanel (المضيف، اسم القاعدة، المستخدم، كلمة السر).
3. افتح موقعك في المتصفح → يظهر **معالج التثبيت** تلقائيًا (`/install`).
4. أدخل بيانات قاعدة البيانات + اسم المتجر + حساب المدير → اضغط تثبيت.
5. احذف مجلد `install` (أو اتركه — يقفل نفسه تلقائيًا بعد التثبيت).

## المتطلبات
- PHP 8.0 أو أحدث (مع PDO MySQL، mbstring)
- MySQL 5.7+ / MariaDB 10.3+
- Apache مع mod_rewrite (للوظائف الكاملة)

## الدخول
- المتجر: `https://yourdomain.com/`
- لوحة التحكم: `https://yourdomain.com/admin`
